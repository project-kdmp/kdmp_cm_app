# 2.2.1 (206)

2026-10-05 · 기준 버전 2.2.0(205)

**2.2.0 의 기사 지정 화면 버그 둘을 고친 버전이다.** 기능 추가는 없다.

2.2.0(205) 을 내부 테스트에 올려 눌러보는 과정에서 나왔다. 그 빌드에도 기사지정은
동작했지만 하단 버튼 글자가 두 줄로 내려가고, 안내 문구가 실제 정책과 달랐다.

## 스토어 제출용 (Play Console 붙여넣기)

내부 테스트 트랙 전용이다. 프로덕션으로 승격하지 않는다.

```
기사 지정 화면을 고쳤습니다.

- 하단 버튼의 글자가 두 줄로 내려가던 문제를 고쳤습니다.
- 지정한 기사의 응답을 기다리는 시간 안내가 실제와 다르던 문제를 고쳤습니다.
```

| 내용 | 커밋 |
|---|---|
| 하단 버튼 글자가 두 줄로 내려가고 안내 문구가 사실과 달랐다 | `86dd58b` |

## 1. 버튼이 두 줄로 내려갔다

기기 폭 384dp 에서 버튼 한 칸은 `(384 − 40 − 8) / 2 = 168dp` 이고, `CustomRadiusButton`
의 기본 좌우 패딩 24 가 48dp 를 먹어 글자 자리는 120dp 였다.
「기사 지정 없이 호출」은 기본 글자 크기에서 **129.7dp** 라 9.7dp 가 넘쳤다
(실기기 `TextPainter` 측정).

**패딩이나 문구만 손대는 것으로는 부족했다.** 이 앱은 텍스트 크기를 16·19·22
세 단계로 바꿀 수 있다(`CustomTextMode`).

| 조치 | 16 | 19 | 22 |
|---|---|---|---|
| 문구만 단축 | ✓ | ✓ | ✗ |
| 패딩만 24→12 | ✓ | ✗ | ✗ |
| 둘 다 (384dp) | ✓ | ✓ | ✓ |
| 둘 다 (**360dp**) | ✓ | ✓ | **✗ −0.4dp** |

폭 360dp 기기의 22 에서는 두 문구가 패딩까지 각각 175~180dp 를 요구하는데 한 칸이
156dp 다. 가용 폭 312dp 를 두 버튼이 꽉 채워 **어떤 패딩·flex 조합으로도 자리가
나지 않는다.**

**두 버튼을 위아래로 쌓았다.** 전체 폭을 쓰면 글자 자리가 296dp(384) / 272dp(360) 라
가장 큰 글자(178.3dp) 에도 크게 남는다.

쌓은 뒤엔 길이 여유가 충분하지만 「기사 지정 없이 호출」의 "기사" 는 화면 제목
(「기사 지정」)과 겹쳐 떼어 「지정 없이 호출」로 뒀다. 옆 버튼 「지정하고 호출」과도
짝이 맞는다.

`CustomRadiusButton` 에 `padding` 파라미터를 더하려다 **되돌렸다.** 쌓기로 하면서
불필요해졌고, 이 위젯은 11개 화면이 쓴다.

## 2. 안내 문구의 「60초」가 사실과 달랐다

```
전: 지정한 기사가 60초 안에 수락하지 않으면 자동으로 일반 배차로 전환됩니다.
후: 지정한 기사가 일정 시간 안에 수락하지 않으면 자동으로 일반 배차로 전환됩니다.
```

실제 유효시간은 `kdmp_adm_feepolicy.timeout_min`(`adm_feepolicy_tp='DRVF'`) 정책값이고
**현재 30분**이다. 앱·서버 어디에도 60초 로직이 없었다.

> 고객이 1분만 기다리면 된다고 읽고 30분을 기다리게 된다.

운영이 관리자 요율정책 화면에서 바꾸는 값이라 **숫자를 박지 않는다.** 박으면 바꿀
때마다 앱을 다시 내야 하고 그 사이 문구가 거짓이 된다.

콜 진행 화면(`appoint_wait_notice.dart`)은 서버가 내려주는 `appointExpireDt` 로 실제
남은 시간을 보여준다. 선택 화면에는 아직 콜이 없어 그 값이 없으므로 숫자를 뺐다.

## 확인하지 못한 것

**쌓인 버튼을 눈으로 보지 못했다.** 기사 지정 화면은 출발지·도착지를 넣고 기사 선택을
눌러야 도달한다. 오버플로는 계산상 해소되지만 **모양이 보기 좋은지는 이 빌드로
확인해야 한다.** 디자인이 바뀌는 변경이므로 내부 테스트에서 가장 먼저 볼 것이다.

푸시를 눌렀을 때 콜 상세로 들어가는 것을 **포그라운드·백그라운드·종료 세 경로 모두**
실기기로 확인했다 (`kdmp-msa-servers#164`, `kdmp_dm_app#21`).
