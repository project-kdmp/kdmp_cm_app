## 기사앱과 같은 심볼로 맞췄다

두 앱이 같은 협회를 쓰는데 아이콘이 다르면 고객과 기사가 서로 다른 서비스로 본다.
기사앱 2.8.14 와 **같은 파일**을 쓴다.

종전 엠블럼은 원형 테두리에 '사단법인 한국 플랫폼 모빌리티 협회 / KOREA PLATFORM
MOBILITY ASSOCIATION' 글자가 둘려 있었다. **런처 크기에서는 그 글자가 읽히지 않고,
자리만 차지해 가운데 심볼이 작아 보인다.**

아이콘(Android 5종·iOS 전체·`assets/kpma_logo.png`)은 이미 교체돼 있었으나 커밋되지
않은 채였다. 화면 로고와 온보딩까지 함께 갈아 어긋남을 없앴다.

**화면 로고는 흰 배경을 투명으로 바꿔 넣었다.** 원본(`assets/kpma_logo.png`)은
`hasAlpha=no` 라 그대로 쓰면 다크모드에서 흰 사각형이 생긴다. 가장자리에서 이어진
흰색만 지웠다(플러드 필) — 로고 안쪽의 흰색은 그림의 일부라 함께 지우면 모양이
무너진다.

온보딩은 로고·글자가 한 장에 합성된 PNG 라 로고만 갈 수 없다. 엠블럼 자리를 지우고
새 심볼을 같은 크기로 올렸다. **배경도 함께 걷었다** — light 는 흰색, dark 는
`#E5E5E5` 불투명이라 화면 위에 사각형으로 떠 보인다.

## 회원 혜택은 앱이 그리지 않는다

혜택 내용은 협회가 웹(k-pma.or.kr)에서 관리한다. 앱이 목록을 그리면 바뀔 때마다 앱을
올려야 하므로 그 페이지를 웹뷰로 띄운다. **기사앱의 '기사혜택' 과 같은 페이지**다.

주소는 환경별로 갈린다 (`AppConstants.BENEFIT_URL`).

| 환경 | 주소 |
|---|---|
| dev | `http://stage.k-pma.or.kr/benefits/legal` |
| stage | `http://stage.k-pma.or.kr/benefits/legal` |
| prod | `https://k-pma.or.kr/benefits/legal` |

dev 전용 주소를 받지 않아 stage 와 같은 곳을 본다. stage 는 `http` 인데
`usesCleartextTraffic="true"` 가 이미 있어 막히지 않는다.

메뉴에서는 **고객센터 바로 위, 구분선 아래 묶음의 맨 위**에 둔다.

## 외부 사이트라 손을 더 봤다

앱이 내용을 보장하지 못한다.

- **받아오는 동안 진행 표시.** 흰 화면만 보이면 멈춘 것처럼 보인다
- **열지 못하면 까닭과 '다시 시도'.** 빈 화면만 남으면 고객이 앱 탓으로 여긴다
- **메인 프레임 오류만 가린다.** 페이지 안 이미지 하나가 실패해도
  `onWebResourceError` 가 불려서, 그대로 두면 멀쩡한 화면을 오류 화면이 덮는다

## 확인한 것

실기기(SM-S926N, Android 16)에 debug 빌드를 올려 stage 로 확인했다.

- 애플리케이션 정보에서 **아이콘이 새 심볼로 바뀐 것**을 확인
- 메뉴에 **'회원 혜택'** 이 보인다 — 구분선 아래, 고객센터 위
- 눌렀을 때 협회 페이지가 정상 렌더링. `홈 > 회원혜택 > 법률` 경로로 들어가고
  법률·세무·의료·부동산·프랜차이즈 탭이 보인다
- 두 주소 모두 직접 호출해 HTTP 200(63KB) 확인
- `fvm flutter analyze` — 새 화면 `No issues found`

## 확인하지 못한 것

- **prod 주소를 기기에서 열어 보지 못했다.** debug 빌드는 stage 를 본다. 주소 자체는
  HTTP 200 을 확인했고 응답 크기가 같다
- **온보딩·화면 로고의 실제 화면을 보지 못했다.** 기사앱 2.8.14 에서 같은 처리를
  검증했고 들어간 파일도 같다
- iOS 는 빌드·설치 모두 해보지 않았다

## adaptive icon 은 없다

`mipmap-anydpi-v26/` 가 없어 Android 8 이상에서도 PNG 를 그대로 쓴다. 원형 심볼이라
지금은 문제되지 않지만, 모서리까지 쓰는 도안으로 바꿀 때는 함께 넣어야 한다.

## 앱 이름은 그대로다

`android:label` 과 `CFBundleDisplayName` 이 **'콜프렌드 고객용'** 이다. 아이콘만
협회 심볼로 바뀌어 홈 화면에서 둘이 어긋나 보인다 — 기사앱도 같은 상태로 두었다.
