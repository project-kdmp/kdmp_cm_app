# 2.2.12 (218)

2026-11-01 · 기준 버전 2.2.11(217, 내부 테스트)

**온보딩 글자 속에 박혀 있던 회색을 지운다.** 2.2.11 에 들어간 흠을 고치는 판이다.

## 스토어 제출용 (Play Console 붙여넣기)

```
[고친 점]
· 첫 실행 안내 화면의 글자가 깨져 보이던 문제를 고쳤습니다.
```

## 담긴 것

| 내용 | 커밋 |
|---|---|
| 온보딩 배경을 투명 대신 흰색으로 | `359ed53` |

## 플러드 필이 글자에는 맞지 않았다

2.2.11 에서 온보딩 배경을 투명으로 만들 때 가장자리에서 이어진 곳만 지우는 플러드
필을 썼다 — 로고 안쪽의 흰색은 그림의 일부라 함께 지우면 모양이 무너지기 때문이다.

**글자에는 그 판단이 맞지 않았다.** '용'·'ㅇ'·'8' 처럼 막힌 공간은 바깥과 이어져
있지 않아 배경색이 그대로 남았다. 글자마다 회색 칠이 박힌 것처럼 보인다.

```
남아 있던 배경색 픽셀
  img_onboarding1_light   1,668px
  img_onboarding1_dark    6,020px
```

투명화를 되돌리고 원본 배경을 그대로 쓴다. 고객앱 light 는 원본이 이미 흰색이라
흰 화면과 섞인다.

## dark 는 원본 그대로 둔다

dark 이미지는 **원본부터 흰 글자에 `#E5E5E5` 배경**이라 다크모드에서 글자가 보이지
않는다. 이번 변경과 무관한 기존 문제라 따로 다룬다.

## 확인한 것

- 세 앱의 '고용노동부 제823호' 부분을 2배로 확대해 나란히 대조 — 고객앱은 회색 칠이
  사라졌다
- Play 실물 조회로 다음 versionCode 를 정했다(최대 217)

## 확인하지 못한 것

- **기기에서 온보딩 화면을 다시 띄워 보지 못했다.** 이미지 파일을 확대해 확인했다
- iOS 는 빌드·설치 모두 해보지 않았다
