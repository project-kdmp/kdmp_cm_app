## 바꾼 곳

| 자리 | 쓰이는 데 |
|---|---|
| `lib/presentation/values/strings.dart` | 화면 문구 |
| `android/.../AndroidManifest.xml` | 런처 이름 |
| `ios/Runner/Info.plist` | iOS 표시 이름 |

세 앱이 같은 이름을 쓰므로 함께 바꿨다.

**`docs/` 아래 출시노트와 기획 문서는 건드리지 않았다.** 그때 그 이름으로 적은
지난 기록이라 고치면 당시 사실과 어긋난다.

## 확인한 것

- 앱 코드·매니페스트·plist 에 `콜프렌드` 잔여 0곳
- `fvm flutter analyze` — error 0
- Play 실물 조회로 다음 versionCode 를 정했다

## 확인하지 못한 것

- **기기에서 바뀐 이름을 보지 못했다.** 문자열 치환이라 위험은 낮다
