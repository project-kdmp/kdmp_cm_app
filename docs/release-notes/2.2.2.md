# 2.2.2 (207)

2026-10-06 · 기준 버전 2.2.1(206)

**기사 지정 화면이 소프트키에 가려지던 버그를 고친 버전이다.** 기능 추가는 없다.

실기기에서 눌러보니, 소프트키(3버튼 내비게이션)가 있는 기기에서 기사 지정 화면
하단의 「지정 없이 호출」·「지정하고 호출」 버튼이 내비게이션 바 뒤로 들어가 잘렸다.
같은 화면의 기사 상세 팝업도 하단이 같은 식으로 가려졌다.

## 스토어 제출용 (Play Console 붙여넣기)

내부 테스트 트랙 전용이다. 프로덕션으로 승격하지 않는다.

```
기사 지정 화면의 표시 문제를 고쳤습니다.

- 소프트키(내비게이션 바)가 있는 기기에서 화면 하단의 '지정 없이 호출', '지정하고 호출' 버튼이 소프트키에 가려지던 문제를 고쳤습니다.
- 기사 상세 팝업도 같은 방식으로 하단이 가려지지 않게 했습니다.
```

## 원인과 조치

`showModalBottomSheet`(기사 상세 팝업)과 화면 하단 버튼이 **하단 시스템 인셋을
더하지 않았다.** 소프트키가 있는 기기에서 내비게이션 바 높이만큼 콘텐츠가 바 뒤로
들어갔다.

앱의 다른 바텀시트·버튼이 쓰는 관례(`MediaQuery` 의 `viewInsets.bottom` +
`padding.bottom`)를 그대로 적용했다. `work_screen.dart` 의 `ReviewBottomSheet` 등과
같은 방식이다.

- 기사 상세 팝업 — `Wrap` 안에서 시트를 `Padding(viewInsets + padding.bottom)` 으로 감쌌다.
- 화면 하단 버튼 — 버튼 `Padding` 에 `padding.bottom` 을 더했다.

## 확인하지 못한 것

**기사 상세 팝업은 실제로 띄워보지 못했다.** STAGE 에 대기 중인 기사가 없어 세 탭
(최근 이용·단골·주변 대기)이 모두 비어, 기사를 눌러 상세 팝업을 여는 경로에 도달하지
못했다. 화면 하단 버튼과 동일한 인셋 처리라 함께 적용되지만, 모양은 내부 테스트에서
기사 목록이 찰 때 확인할 것이다.
