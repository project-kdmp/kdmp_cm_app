# 2.2.3 (208)

2026-10-06 · 기준 버전 2.2.2(207)

**예약 화면이 소프트키에 가려지던 버그를 고친 버전이다.** 기능 추가는 없다.

2.2.2 의 기사 지정 수정과 같은 종류다. 소프트키(3버튼 내비게이션)가 있는 기기에서
예약 바텀시트의 하단 확인 버튼이 내비게이션 바 뒤로 들어가 잘렸다.

## 스토어 제출용 (Play Console 붙여넣기)

내부 테스트 트랙 전용이다. 프로덕션으로 승격하지 않는다.

```
예약 화면의 표시 문제를 고쳤습니다.

- 소프트키(내비게이션 바)가 있는 기기에서 예약 일시·예약 일자·예약 시간 선택 화면의 하단 '확인' 버튼이 소프트키에 가려지던 문제를 고쳤습니다.
```

## 원인과 조치

예약 흐름의 바텀시트 세 개가 `showModalBottomSheet` 호출부에서 **하단 시스템 인셋을
더하지 않았다.** 소프트키 기기에서 내비게이션 바 높이만큼 확인 버튼이 바 뒤로 들어갔다.

앱 관례(`MediaQuery` 의 `viewInsets.bottom` + `padding.bottom`)대로 각 시트를 `Padding`
으로 감쌌다. 2.2.2 의 기사 상세 시트 수정, `work_screen.dart` 의 `ReviewBottomSheet`
와 같은 방식이다.

- 예약 일시 시트 — `home_screen.dart` 의 호출부
- 예약 일자 선택 시트 / 예약 시간 선택 시트 — `reservation_bottom_sheet.dart` 의 호출부

예약 정보 확인 팝업은 이미 `useSafeArea: true` 라 손대지 않았다.

## 확인하지 못한 것

**예약 시간 선택 시트는 따로 띄워보지 못했다.** 예약 일자 선택과 같은 호출부·같은
패턴으로 고쳤고, 일자 선택 시트는 실기기로 확인했다. 시간 시트는 내부 테스트에서
함께 볼 것이다.
