# 2.2.4 (209)

2026-10-08 · 기준 버전 2.2.3(208)

**홈 호출 화면의 버튼 구성을 바꾼 버전이다.**

요금·결제 아래에 있던 기사 지정 행(선택/변경)을 없애고, 하단 버튼을 둘로 바꿨다.
예약(예약 일시 지정 호출)은 홈에서 뺐다.

## 스토어 제출용 (Play Console 붙여넣기)

내부 테스트 트랙 전용이다. 프로덕션으로 승격하지 않는다.

```
호출 화면을 간단하게 바꿨습니다.

- '지정기사 호출': 기사를 골라 그 기사에게 먼저 호출합니다.
- '바로 호출하기': 기사 지정 없이 자동 배차로 바로 호출합니다.
- 기사 지정 줄을 없애고 두 버튼으로 정리했습니다.
```

## 바뀐 동작

- **지정기사 호출**: 기사 선택 화면(최근 이용·단골·주변 대기)으로 가서 기사를 고른 뒤
  바로 호출까지 이어간다. 그 화면에서 「지정 없이 호출」을 고르면 자동 배차로 호출한다.
- **바로 호출하기**: 기사 지정 없이 자동 배차로 즉시 호출한다.
- 호출 흐름(유의사항→차량선택→콜 요청→운행 화면)은 두 버튼이 공유한다.
- 예약하기는 홈에서 제거했다. 예약 요청 레이어(usecase·repo)와 예약 바텀시트 위젯은
  남겨 뒀다 — 진입점만 걷어낸 것이다.

두 버튼은 기존처럼 좌우로 나란히 둔다. 「바로 호출하기」 라벨이 길어져 아이콘 여백·
패딩을 줄여 한 줄에 들어가게 했다.

## 확인한 것

**실기기(SM S926N · Android 16 · 3버튼 소프트키)에서 전 흐름을 눌러 확인했다.**

- 나란히 버튼 배치, 「바로 호출하기」 한 줄 표시, 기사 지정 행 제거
- 바로 호출하기 → 자동 배차 콜 접수(`appointDmNm` 없음) → 운행 화면. 취소까지 확인
- 지정기사 호출 → 기사 선택 화면 이동, 기사 목록 표시
- 기사 상세 팝업이 소프트키에 가리지 않음 (2.2.2 수정 재확인)
- 기사 선택 화면에서 뒤로가기 → 홈 복귀, 지도 복원, 콜 미발생
- `fvm dart analyze lib` error 0, 릴리스 번들 빌드·서명
- `pubspec.lock` 변동 없음, Flutter 3.35.7

## 남은 것

**지정하고 호출(지정 기사로 실제 콜 접수)까지는 접수하지 않았다.** 테스트 콜을 남기지
않으려 기사 선택 화면 이동·팝업까지만 확인했고, 실제 지정 콜 접수는 바로 호출하기와
같은 `_requestCall` 에 지정 기사만 실어 보내는 것이라 흐름은 같다. 내부 테스트에서
지정 콜 접수와 수락까지 확인할 것이다.
