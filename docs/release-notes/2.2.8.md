## 공지 이미지 — 두 가지가 겹쳐 있었다

**첫째, 이미지 경로는 인증을 요구하는데 웹뷰가 토큰을 붙이지 않는다.**
본문은 `InAppWebView` 로 그리고 이미지는 `/datafile/...` 인데, 그 경로는 `22001 NOT_AUTH`
를 돌려준다(2026-10-13 실측). 토큰이 붙는 Dio 로 미리 받아 **data URI 로 본문에 심는다.**

**둘째, 본문의 src 가 경로가 아니라 관리자 프론트의 중계 라우트다.**

```html
<img src="/image?q=%2Fdatafile%2Fadmin%2FNTIE%2F123%2Fpng" width="500">
```

`/image` 는 관리자 프론트가 토큰을 붙여 `/v1/biztotal<경로>` 로 중계해 주는 라우트다
(`kdmp-admin-client/app/routes/image.ts`). 앱에는 그 라우트가 없다. `q` 를 풀어 실제
경로를 꺼낸다.

매치가 0 건이면 조용히 빈 칸이 되어 눈으로는 놓친다. `test/notice_image_src_test.dart`
로 고정했다 — 중계 경로·옛 경로·따옴표 변형·바깥 이미지·`q` 가 파일 경로가 아닌 경우 5건.

## 확인한 것

- `fvm flutter test test/notice_image_src_test.dart` — 5건 통과
- `fvm flutter analyze lib/` — error 0
- **기사용 앱(`kdmp_dm_app` 2.8.1)에서 같은 코드로 실기기 렌더 확인.**
  이 앱에서는 직접 띄워 보지 않았다.

## 프로덕션 승격을 결정하기 전에 볼 것

**2.2.0 부터 2.2.4 까지의 노트가 모두 「내부 테스트 트랙 전용이다. 프로덕션으로 승격하지
않는다」 고 적고 있다.** 그 뒤 2.2.5~2.2.7 에는 노트가 없다.

이 버전을 프로덕션에 올리면 **그 모든 변경이 한꺼번에 처음 나간다** — 기사 지정 UX,
호출 화면 버튼 구성, 운행중 기사 제외 등. 공지 이미지 하나만 나가는 것이 아니다.

승격할지, 공지 이미지 수정만 따로 떼어 올릴지는 그 범위를 보고 정해야 한다.
